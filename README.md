# E-Commerce Sales Dashboard 

## Overview
This project features an interactive E-Commerce Sales Dashboard designed to monitor and analyze high-level business Key Performance Indicators (KPIs). The dashboard transforms raw sales data into actionable business insights, tracking total sales volume, overall profitability, and average order value (AOV) to help stakeholders understand regional performance and consumer purchasing behaviors.

## Key Insights & Metrics
* **Core KPIs:** Tracks a total sales amount of 438K, a net profit of 37K, and an AOV of 121K.
* **Regional Performance:** Identifies Maharashtra as the highest revenue-generating state (102K), followed by Madhya Pradesh and Uttar Pradesh.
* **Consumer Behavior:** Highlights a strong customer preference for Cash on Delivery (44% of transactions) and UPI (21%).
* **Product Analytics:** Reveals that the "Clothing" category dominates sales volume (63%), while providing a granular look at profitability across sub-categories like Printers, Bookcases, and Sarees.
* **Temporal Trends:** Maps month-over-month profit fluctuations to pinpoint seasonal performance trends across the fiscal year.

## Visualizations Included
* **Card Visuals:** High-level metrics for Amount, Profit, Quantity, and AOV.
* **Bar & Column Charts:** Amount by State, Profit by Sub-Category, and Profit by Month.
* **Donut Charts:** Quantity by Payment Mode and Quantity by Category.

## Project Structure
* `data/`: Contains the raw `.csv` or `.xlsx` datasets used for analysis (if applicable).
* `dashboard/`: Contains the `.pbix` file.
* `images/`: Screenshots of the dashboard for preview purposes.

## How to Use
1. Clone the repository to your local machine.
2. Open the `.pbix` file using Power BI Desktop.
3. Review the data model and DAX queries to understand the underlying logic.
4. Interact with the visuals by clicking on specific states, categories, or payment modes to filter the data dynamically.
